SUPREME DEITY HELL / HARD BOT

1. Extract the entire ZIP into a normal writable folder. Do not run inside the ZIP.
2. Install 64-bit Python 3.12 for Windows with tkinter and the Python launcher.
3. Double-click Setup.cmd once. Internet is needed to install Python dependencies.
4. Double-click Start Supreme Deity.vbs.
5. Keep the 7DS Global client visible. If the game runs as administrator, use
   Restart as administrator in the launcher. Choose clears and press Start.
   Use Resize game before starting if needed (518 x 922 game area, matching the successful SD run).
6. Stop or F8 stops input. New logs are created in scripts/logs.

Team: Odin / LR Freyr / green Hel / Gawain. Choose Hell or Hard in Run setup.
Hard uses five crystals, a 20-minute run timeout and a T5 Phase 3 finishing burst
on the alternate route. Hell retains four crystals and the existing T4 burst.
Extra turns continue with filler cards, preserving burst and stance-removal
resources where possible. Category limits and target verification still apply.
Includes the latest working battle policy and Complete-screen OK recognition fix.
Start from the tavern (with the bottom Battle button visible), Battle menu,
Supreme Deity menu or Hell team setup for a new run. Click Start to navigate
to Supreme Deity, enter Hell and start fighting automatically.

This is a runtime package, not a bundled Python executable. Setup creates its own
.venv so it does not depend on the original computer's Python path. No account
passwords, notification channels, previous logs, recordings, test fixtures or
existing Python environments are included. Shared framework modules and their
referenced assets are retained for runtime dependencies. Battle code is unchanged.
Some older GUI/check wording still says that live completion is unverified;
the current version has completed a user-confirmed live run.

GUI: abort limit defaults to 10. Wins and elapsed time reset when Start is pressed and remain visible when the run ends. Team gear/food/cardset notes appear below the lineup.
The Battle tab contains the phase/turn monitor, log, original character portraits,
team links, gear/food notes and Card set No. 78. Target verification is shown only
when reported by the bot and cleared on the next turn or an uncertain context.
Use the Display tab for 2560 x 1440 or 1920 x 1080 at 125%, Restore display,
Check installation and Update from GitHub. Admin restart is in the header.

Pause changes to Resume and keeps the current run state and wins. Active elapsed time and bot timeout clocks freeze while paused. Stop/F8 also works while paused. Game animations already in progress may continue. Resume checks the current screen before acting.
