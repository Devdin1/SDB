## Installation

### 1. Requirements

- Windows 10/11
- [Python 3.12 (64-bit)](https://www.python.org/downloads/) with tkinter and Python Launcher
- 7DS Grand Cross Global PC client

### 2. Clone the Repository

Open Git Bash or Command Prompt:

```bash
git clone https://github.com/Devdin1/artfork.git
```

Navigate to the project folder:

```bash
cd artfork
```

### 3. Install Dependencies

Run the setup script once:

```cmd
Setup.cmd
```

An internet connection is required for the initial installation.

### 4. Launch Supreme Deity Hell

Start the application:

```cmd
"Start Supreme Deity.vbs"
```

### 5. Start Farming

1. Keep the 7DS Global client visible.
2. Restart the launcher as administrator.
3. Select the number of clears and press **Start**.
4. Use **Resize game** or the **Display** tab if needed.

**Supported display configurations:**
- 2560 × 1440 at 125%
- 1920 × 1080 at 125%

### Updates & Logs

Use **Update from GitHub** in the launcher to check for updates.


**SUPREME DEITY HELL**

1. Extract the entire ZIP into a normal writable folder. Do not run inside the ZIP.

2. Install 64-bit Python 3.12 for Windows with tkinter and the Python launcher.

3. Double-click Setup.cmd once. Internet is needed to install Python dependencies.

4. Double-click Start Supreme Deity.vbs.

5. Keep the 7DS Global client visible.<br>
   Restart as administrator in the launcher.<br>Choose clears and press Start.<br>
   Use Resize game before starting if needed.

6. Use the Display tab for 2560 x 1440 or 1920 x 1080   at    125%, Restore display,
   Check installation and Update from GitHub. Admin restart is in the header.

7. Stop stops input. New logs are created in scripts/logs.
